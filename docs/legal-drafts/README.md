# Юридические документы MFT39: редакция 2026-11-15.1

Владелец проекта 15.11.2026 подтвердил реквизиты Федерации, официальный email tkdmft39@mail.ru и утверждение документов тренером. В отдельном уточнении согласованы срок двух согласий по 31.12.2099 включительно с возможностью досрочного отзыва и хранение по целям обработки/другим законным основаниям вместо безусловного бессрочного хранения. Имя тренера, полномочия по внутренним документам Федерации и отдельный подписанный акт в проект не предоставлялись; они не выдуманы.

Полные четыре текста находятся в этой папке. Статус approved и метаданные реестра отражают полученное подтверждение владельца проекта. Это не утверждение о выполненном юридическом аудите организации или проверке действующего хостинга.

## Содержание текущего выпуска

- Подтверждены оператор и имеющийся email. Поля со сроками заполнены.
- Для согласий указан конец 2099 года. Дата не отменяет право отзыва и не создаёт самостоятельного права хранить сведения до 2099 года после прекращения целей.
- В политике изложены критерии хранения по категориям, без произвольно назначенных лет.
- Запись взрослого и год рождения приведены в соответствие с существующими формой и API.
- В согласии представителя уточнены имеющиеся в заявке желаемая дата и добровольный комментарий.
- Электронное подтверждение представителя прямо отделено от проверки его полномочий оператором. Автоматическая проверка документов не заявляется.
- Отдельных выдуманных правил секции, процедуры проверки паспортов, сроков ответа почты или расписания удаления не добавлено.
- Разрешение на фотографии, рекламу и публичное распространение данных ребёнка по-прежнему не предоставляется.

## Источники и проверка

Первоначальный источник политики — предоставленный владельцем файл (14422 байта, 165 строк, прочитан полностью); три других текста предоставлены в сообщении. Первоначальная редакция сохранена в истории Git, оригинал вложения не изменялся. Email первоначально найден в contacts.email, src/content/site.content.ts, затем подтверждён владельцем.

registry.json содержит статус, версию, дату и обозначение согласовавшего лица. npm run legal:generate формирует общий backend/resources/legal-documents.json для PHP и frontend с SHA-256 полного нормализованного текста UTF-8/LF. npm run legal:check проверяет точное совпадение; npm run legal:release-check запрещает черновики, незаполненные поля и неполное утверждение. Новые тексты нельзя изменять под старой принятой пользователями версией.

Справочные источники: [152-ФЗ, статья 5](https://www.consultant.ru/document/cons_doc_LAW_61801/96fbc469f91f57235cc842a85e0516a99f23dc85/), [152-ФЗ, статья 9](https://www.consultant.ru/document/Cons_doc_LAW_61801/6c94959bc017ac80140621762d2ac59f6006b08c/), [Яндекс ID: сведения пользователя](https://yandex.ru/dev/id/doc/ru/user-information).

## Фактические ограничения перед включением

См. OPERATIONS_RU.md: действующие журналы, место хранения резервных копий, организация проверки полномочий и обработки обращений требуют фактической проверки ответственными лицами. Редактор документов не получил доступ к ISPmanager, действующей базе или реальным аккаунтам. Положение о российском размещении основной базы основано на сообщённой архитектуре; если фактическое размещение иное, активацию следует остановить до устранения расхождения.

Код сохраняет Яндекс ID, имя и серверную сессию при OAuth ещё до послевходового экрана документов. Экран принятия не означает отсутствие обработки до входа; основание и информирование для этой начальной операции оператор оценивает отдельно. Принятие документов не подменяет такое основание.

Критерии хранения не являются добавленной автоматической очисткой. Архивирование сохраняет данные. Существующее подтверждённое удаление карточки удаляет и связанные подтверждения представителя, сохраняя минимальный обезличенный след аудита. Перед удалением необходимо оценивать остающуюся необходимость хранения доказательств. Если фактические обязанности требуют другого жизненного цикла, он согласуется и дорабатывается отдельно.

Все изменения поставляются без автоматической миграции production и без включения LEGAL_ENFORCEMENT. Установка: backend/docs/DEPLOYMENT_LEGAL_RU.md.
