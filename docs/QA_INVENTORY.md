# Общий перечень QA

Построен по разделам 1–39, реализованным контролам и планируемым заявлениям итогового отчёта. Используется для функциональной и визуальной проверки; галочки ставятся только после фактической проверки, результаты — TEST_REPORT.md.

| Требование / видимое действие | Функциональная проверка | Видимая проверка / доказательство |
|---|---|---|
| Hero и первая сессия | Intro ~3с, авто, cursor, drag/inertia, repeat session | Начальный, промежуточный и финальный desktop кадры, читаемый девиз/CTA |
| Mobile Hero | CTA сразу, scroll двигает карусель, нативный скролл | 360/390/430, CTA и меню выше карусели |
| Reduced motion / motion off | Нет обязательного intro/auto, контролы работают | Desktop и mobile, текст/CTA сразу |
| Все секции и обе темы | Порядок из общей модели, toggle туда/обратно | Восемь ширин, dark/light, все видимые регионы без clipping |
| Навигация/маршруты | Desktop/mobile menu, прямые URL, back/forward, gallery anchor, 404 | Активный пункт/заголовок, desktop/mobile header и footer |
| Demo flow | Guest CTA → login → account → booking, child/adult, дата, demo-result, logout | Все состояния имеют demo-маркировку, нет подтверждённой записи |
| Карты | Три зала, Яндекс/2ГИС туда/обратно, ссылки | Выбранный зал/адрес/часы/честный fallback |
| Контакты | Clipboard success/denied, tel mobile, mailto, Gmail | Уведомление после успеха, ошибка при отказе, все действия видимы |
| Галерея | Drag/инерция, prev/next, open/close, Escape, keyboard/focus | Пространственный обзор, открытый кадр и возврат |
| RuTube/VK | Отсутствие данных, реальный ручной контракт, official links | Пустые состояния без фиктивного контента |
| Редактор текста | Меняется девиз/контакты/страничные тексты, save/reload | Предпросмотр и публичная страница показывают то же значение |
| Редактор структуры | Порядок/видимость, add/remove coach/location/event | Обновлённые соответствующие страницы |
| Редактор медиа | File/path, ratio, focus, alt, sort, visibility, remove | Превью, точка фокуса, реальное изображение на сайте |
| Темы/motion в редакторе | Цвета, тема, допустимые пределы, переключение эффектов | Три preview размера, разные themes, live changes |
| История/данные | Undo/redo, block/all reset, save/reload, export/import | Сохранённый статус, корректно восстановленная конфигурация |
| Неверный импорт | Invalid JSON/schema/URL отклоняется без потери текущего | Понятное сообщение, прежняя страница работает |
| Необычные сценарии | Галерея → Escape → back; быстрые route/theme изменения | Фокус/слои/стабильность после действий |
| Границы данных | Нет отправки анкеты/реального OAuth/ПД в storage | Network/storage evidence, фиксированные вымышленные поля |

Отдельно: 30–90 секунд исследовательского прохода обычными действиями, без предварительной подстановки состояния. Визуальную целостность и отсутствие clipping проверять скриншотами, а не только scrollWidth. Не заявлять Firefox/Safari, если соответствующие движки не запускались.
